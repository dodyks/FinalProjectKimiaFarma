# FinalProjectKimiaFarma

Background
Performance evaluation of Kimia Farma's business from 2020-2023 to understand the role of a Big Data Analyst in processing and analyzing company transaction data.
Data Sources
     kf_final_transaction.csv - Transaction data
     kf_inventory.csv - Inventory data
     kf_kantor_cabang.csv - Branch office data
     kf_product.csv - Product data
Project Challenges
1. BigQuery Data Import
Importing 4 datasets into BigQuery tables
2. Data Aggregation Analysis
Creating analysis tables by combining all data
Calculating profits based on price categories
3. Looker Studio Visualization
Business performance dashboard 2020-2023 and branch transaction analysis
Indonesia's profit mapping by province and additional insights
